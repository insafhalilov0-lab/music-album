# music-album

Промо-страница музыкального альбома группы «Эхо».

## Что использовал
- HTML: заголовки, параграфы, ссылки, перенос строки (`<br>`)
- CSS: цвет текста, фоновое изображение, `background-size: cover`, `background-attachment: fixed`, `min-height: 100vh`

## Чему научился
- Делать фиксированный фон, который не прокручивается
- Работать с `min-height` вместо `height` для длинных страниц
- Делать текст читаемым на фоне картинки
